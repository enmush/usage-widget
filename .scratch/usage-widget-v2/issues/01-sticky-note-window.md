# 01: Sticky-note window with its own minimize button

**What to build:** The widget is a normal desktop window (not always on top) with a taskbar button and app icon. A minimize button on the header sends it to the taskbar; clicking the taskbar button restores it at the same place and brings it to the front. The tray icon is gone; the right-click menu offers Refresh, Accounts…, Start with Windows and Exit.

**Blocked by:** None (can start immediately).

**Status:** done (v0.2.0)

- [x] Other windows can cover the widget
- [x] Header minimize button minimizes; taskbar click restores at the same position
- [x] No tray icon remains
